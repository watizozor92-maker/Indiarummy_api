5. 获取游戏注单记录

请求方法: post url: /game/transaction Content-Type: application/json

body: { "agency_uid": "agency10000",//替换商户id "timestamp": 1762414122945, "payload": "(aes-256-ecb encryption text)" }

payload 字段:

参数 说明 数据类型 必填
from_date 开始日期（UTC+0时间戳到毫秒） long 是
to_date 结束日期（UTC+0时间戳到毫秒） long 是
page_no 页码 int 是
page_size 页大小（最小：1，最大：5000） int 是

返回内容:

{
    "code": 0,
    "msg": "succ",
    "payload": {
        "launch_url":  {"records":[{"agency_uid":"abc"...},{}...],"total_page":1000....}
    }
}
参数名 数据类型 描述 是否必填
code Int 代码 是
msg String 消息 是
payload JSONString 返回结果 是

payload内的参数

参数名 数据类型 描述 是否必填
total_count Int 总条数 是
current_page Int 页码 是
page_size Int 页大小 是
records JSONArray JSON数组 是

records内的参数

参数名 数据类型 描述 是否必填
agency_uid String 代理识别码 是
account String 玩家账号名 是
bet_amount String 下注金额 是
win_amount String 赢的金额 是
currency_code String 币种 是
serial_number String 唯一编号 是
game_round String 游戏局号 是
game_uid String 游戏UID 是
timestamp long 交易时间戳 是

加密说明

payload: 使用 AES-256-ECB 加密算法 并使用base64 对加密内容进行编码; 解密时,按照先base64解码再 AES-256-ECB 解密的顺序即可得到 原文 密钥: 通过 game/applykey 接口申请后自行妥善保存
